# Prime Auto — своя витрина машин из дилерского кабинета

Программа заходит под твоим дилерским логином на primeauto.ge, собирает
твои машины и показывает их на твоём сайте — независимо от primeauto.

## Статус

- [x] Парсер страницы товара (`scraper.py`) — VIN, марка, модель, год, цвет,
      контейнер, дата прибытия, перевозчик, фото.
- [x] **Логин в кабинет через браузер (`login.py`)** ← сейчас здесь.
- [ ] Сбор списка твоих машин из кабинета.
- [ ] Хранилище + витрина на твоём сайте.
- [ ] Синхронизация по расписанию.

## Настройка (один раз)

```bash
# 1. Зависимости
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium

# 2. Впиши логин/пароль от кабинета
#    открой .env и заполни PRIMEAUTO_LOGIN и PRIMEAUTO_PASSWORD
```

Пароль хранится только в `.env` (в `.gitignore`, в git не попадает) и
нигде не печатается.

## Вход в кабинет

```bash
python3 login.py            # откроется окно браузера — если будет капча/2FA,
                            # пройди руками; сессия сохранится в auth.json
python3 login.py --check    # проверить, жива ли сессия
```

После успешного входа появляется `auth.json` — сохранённая сессия.
Все следующие скрипты сбора данных используют её без повторного пароля.

## Безопасность

- `.env` и `auth.json` — секреты, оба в `.gitignore`.
- Пароль не логируется и не хранится в коде.
- При сбое входа скриншот и HTML пишутся в `debug/` для диагностики
  (проверь, что там нет лишнего, прежде чем кому-то показывать).
